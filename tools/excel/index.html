The $ sign

When you copy a formula, Excel moves every cell reference along with it. A $ freezes the part right after it, so that part stays.

Copyrows down andcolumns right:
the formulathe cell it points at
To copy {{=COUNTIFS(C2:C101,F2)}} down, the data range must not move. Freeze it: {{=COUNTIFS($C$2:$C$101,F2)}}.
{{=STDEV.S($A$2:A4)}} copied 1 row down becomes {{=STDEV.S($A$2:A5)}}. The start is frozen and the end moves, so the range gets one row longer.
